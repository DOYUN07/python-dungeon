# 파이썬 던전

파이썬과 자료구조 문제를 풀어 몬스터를 쓰러뜨리며 던전을 내려가는 브라우저 퀴즈 게임입니다.
설치나 빌드 없이 `index.html` 파일 하나로 동작합니다.

## 실행 방법

- **로컬**: `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
- **GitHub Pages**: 저장소 Settings → Pages에서 `main` 브랜치의 루트(`/`)를 선택하면 `https://<사용자명>.github.io/<저장소명>/`에서 플레이할 수 있습니다.

인터넷 연결이 필요합니다. 폰트는 Google Fonts에서, 코드 작성 모드의 파이썬 엔진은 jsDelivr에서 불러옵니다.

## 게임 방식

- 정답을 맞히면 몬스터에게 데미지를 줍니다(퍼즐과 코드 작성은 2). 3연속 정답부터는 크리티컬로 +1.
- 오답이나 시간 초과는 하트 1개를 잃습니다. 하트가 모두 사라지면 게임 오버.
- 단축키: 보기 선택 `1`–`4`, 다음 `Enter`, 스택 퍼즐 `Q`(PUSH) / `W`(POP), 코드 실행 `Ctrl+Enter`.

### 모드

| 모드 | 설명 |
|---|---|
| 스테이지 | 주제 하나에 집중해 5층을 돌파합니다. 마지막 층은 주제별 보스. 남은 하트로 ★1–3을 받습니다. |
| 무한 던전 | 고른 문제 유형을 섞어 끝없이 내려갑니다. 5층마다 보스가 나오고, 보스를 잡으면 하트 1개를 회복합니다. |

스테이지: 함정의 늪(파이썬 기초) · 스택·큐의 탑 · 해시 성채 · 재귀 동굴 · 탐색의 미궁 · 순회의 숲(트리와 그래프)

### 난이도

| | 하트 | 제한 시간 | 문제 레벨 | 기타 |
|---|---|---|---|---|
| 쉬움 | 5 | ×1.4 | 1–2 | 몬스터 HP 낮음, 퍼즐 작게 |
| 보통 | 3 | ×1 | 1–3 | |
| 어려움 | 2 | ×0.75 | 2–3 | 점수 ×1.5, 퍼즐 크게 |

### 문제 유형

| 유형 | 내용 |
|---|---|
| 출력 예측 | 코드를 읽고 출력을 고릅니다. 답한 뒤 실제로 실행해 볼 수 있습니다. |
| 시간복잡도 | 코드의 Big-O를 고릅니다. |
| 빈칸 채우기 | 빠진 코드를 직접 입력합니다. |
| 코드 작성 | 함수를 작성하면 브라우저에서 실제로 실행해 테스트 케이스로 채점합니다. |
| 스택 퍼즐 | PUSH/POP으로 입력을 목표 순서대로 출력합니다. |
| BFS·DFS 퍼즐 | 무작위 그래프에서 방문 순서대로 정점을 클릭합니다. |
| 트리 순회 | 무작위 이진 트리를 전위·중위·후위·레벨 순서로 클릭합니다. |
| 이진 탐색 | 매 단계 `mid` 칸을 직접 짚어 값을 찾습니다. |

## 문제 추가하기

문제는 `index.html`의 `BANK` 객체에 들어 있습니다. 모든 문제에는 주제 `g`(`basic`, `linear`, `hash`, `rec`, `search`, `tree`)와 난이도 `lv`(1–3)가 있습니다.

```js
// 출력 예측 / 시간복잡도: opts[0]이 정답 (화면에서는 섞여서 나옴)
{ g: "hash", lv: 1, code: `print(len({1, 2, 2}))`, opts: ["2", "3", "1", "오류"], ex: "set은 중복을 제거합니다." }

// 빈칸 채우기: 코드의 ___ 자리, ans는 허용 답안 목록
{ g: "linear", lv: 1, code: `top = stack.___()`, q: "스택 맨 위를 꺼내는 메서드는?", ans: ["pop"], ex: "..." }

// 코드 작성: tests는 [평가할 식, 기대값 식] 쌍
{ g: "rec", lv: 1, title: "재귀 거듭제곱", prompt: "...", starter: `def power(a, n):\n    pass`,
  tests: [["power(2, 10)", "1024"]], sol: `def power(a, n): ...` }
```

## 기술 메모

- 빌드 도구나 프레임워크 없이 HTML, CSS, JavaScript 한 파일로 되어 있습니다.
- 코드 작성 모드는 [Brython](https://brython.info/) 3.13.2로 파이썬을 브라우저에서 실행합니다. 처음 실행할 때 엔진(약 5MB)을 한 번 내려받습니다.
- 사용자 코드는 브라우저의 메인 스레드에서 실행되므로, 무한 루프를 제출하면 탭이 멈춥니다.
- 최고 점수, 별, 설정은 브라우저의 `localStorage`에 저장됩니다.
